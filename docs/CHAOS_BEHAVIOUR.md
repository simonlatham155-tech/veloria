# CHAOS — Harmonic Stochastic Takeover

CHAOS has one musical meaning in both the Veloria and Brown IDSS operating models.

The keyboard/chord defines the harmonic territory. Increasing CHAOS creates autonomous stochastic note events drawn only from the pitch classes of currently held notes, transposed across octaves. These generated notes compete for a finite polyphonic voice budget rather than acting as pitch modulation.

At 0% CHAOS, only explicitly played notes sound. As CHAOS rises, generated harmonic events become denser, wider in octave range, more variable in duration and velocity, and more willing to steal other stochastic voices. At 100%, stochastic notes may dominate the audible texture while the held keys remain the harmonic authority.

The note-event layer is shared by both engines. The selected engine only determines how each generated voice is synthesised internally.
